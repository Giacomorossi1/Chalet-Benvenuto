# Chalet Benvenuto

App per i conti dello chalet: prenotazioni a calendario (Piano Terra e Piano Balconi), costi per piano, cassa, utili, provvigioni e bilancio annuale (esercizio 1 marzo → 28 febbraio).

- L'app è un sito statico pubblicato con GitHub Pages: si installa sul telefono con "Aggiungi a Home".
- I dati **non** sono qui: stanno in un Foglio Google privato, raggiunto tramite lo script in `google-script/Code.gs` e protetto da un PIN.
